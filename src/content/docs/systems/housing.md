## 採集設施

| 設施 | 奇波的工作 | 產出 |
| --- | --- | --- |
| 林果園 | [伐木](/kibo/work/#伐木) | 軟木、硬木、纖維、斑紅菇、紅果、桃荔子、清月果、苦陽果、汁石 |
| 礦場 | [採礦](/kibo/work/#採礦) | 風銅礦、閃錫礦、鏡鐵礦、白銀礦、塵石、堅巖、黃玉、藍晶 |
| 星輝礦場 | [採礦](/kibo/work/#採礦) | 細碎的星結之輝 |
| 元素祭壇 | [元素](/kibo/work/#元素) | 九種屬性的元素微粒 |
| 投食點 | [照料](/kibo/work/#照料) | 新鮮的獸肉、新鮮的禽肉、破損的獸皮、完整的獸皮；偶爾產出奇波蛋 |
| 牧場 | [照料](/kibo/work/#照料) | 放牧的奇波各自的產物（見[牧場](#牧場)） |
| 農場 | [耕作](/kibo/work/#耕作)、[澆水](/kibo/work/#澆水) | 作物：料理與布料的原料（見[農場](#農場)） |

- 採集設施只在派駐做該工作的奇波時產出。
- 春風滿馬的影片說投食點也產蛋與奶，且要先在牧場配置奇波才會產出；第三次測試的遊戲資料與 666bj 的整理都把蛋與奶列為牧場的產物。

## 礦場

- 第三次測試的遊戲資料裡，上表的礦石都出自一座綜合採礦場。公測的礦場有五座（春風滿馬的影片與 666bj 在 NGA 的整理相同），666bj 整理的各礦場產出如下：

| 礦場 | 產出 |
| --- | --- |
| 風銅礦場 | 風銅礦、塵石、黃玉 |
| 閃錫礦場 | 閃錫礦、塵石、黃玉 |
| 鏡鐵礦場 | 鏡鐵礦、堅巖、藍晶 |
| 空鐵礦場 | 空鐵礦、堅巖、白銀 |
| 星輝礦場 | 細碎的星結之輝 |

- 加工設施的產出依春風滿馬的影片與置頂的圖（2026-11-26）；各設施做哪種工作依 666bj 在 NGA 的整理，兩者列的設施相同。
- 加工設施有較大的版本（紡織鋪、製革鋪、熔煉鋪、料理鋪、工作室），做的工作與基本版本相同。
- 春風滿馬的影片提到，加工設施沒有派駐奇波時也會加工，只是很慢。
- 孵化樁孵一顆奇波蛋要 5 小時，派駐的奇波照料評分越高越快。
- 鍛造鋪隨機產出裝備；用織造圖譜可指定產出的裝備。
- 奇波工作會消耗飽腹值，餓了會到奇波餐桌吃那裡的料理；料理由烹飪鍋做。

## 農場

- 農場的田地要搭配耕作小屋，奇波才會自動耕作：做耕作的奇波播種、收割，做澆水的奇波灌溉。
- 一開始只有旱田；家園等級提高後有良田，產量較高，可種特殊果樹。
- 作物有做料理的麥子，以及加工成布料的月麻、棉花。

## 大地圖的設施

- 在大地圖上解鎖的設施永久提高家園對應原料的產能，不必派駐奇波。
