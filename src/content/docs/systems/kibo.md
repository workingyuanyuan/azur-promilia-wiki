## 星彩、閃光與異色

| 個體 | 說明 |
| --- | --- |
| 星彩奇波 | 外觀特殊，例如菜葉帶星空效果的[菜雞](/kibo/caiji/)；屬性與天賦與普通個體相同。同一種奇波可能有多種星彩外觀 |
| 閃光奇波 | 有閃光因子、外觀會閃光的奇波；閃光因子可能出現在普通奇波上，也可能出現在星彩奇波上 |
| 異色個體 | 部分特殊的奇波才有；部分奇波穿上裝扮後，也呈現對應的異色外觀 |

## 專屬奇波

- 專屬奇波是與某位角色締結了契約的奇波個體。做完相關任務，或把該角色的牽絆等級提高，就能直接得到。
- 例如[霜刃狼](/kibo/shuangrenlang/)烏爾是[忒拉拉](/characters/terara/)的專屬奇波；忒拉拉撫摸烏爾時有撫摸普通霜刃狼時沒有的表現。

## 取得

| 方式 | 說明 |
| --- | --- |
| 星結卡 | 步行或騎乘時都能使用，不打斷探索；星結卡的品質影響星結的效果 |
| 幻彩的星結卡 | 特殊的星結卡：容易星結成功，並把星結到的奇波變成星彩奇波 |
| 奇波蛋 | 活動獎勵會給，野外也可能撿到。蛋的品質越高，越可能孵出資質高的奇波；有些特定的蛋孵出的是星彩或閃光個體 |

## 培養

| 培養 | 說明 |
| --- | --- |
| 潛能訓練 | 拿另一隻同名而屬性較高的奇波陪練，提高基礎屬性 |
| 牽絆等級 | 提高奇波的牽絆等級，攜帶它的角色屬性也提高 |

## 因子

- 每隻奇波最多有 8 個因子，捕獲時帶 1 個先天因子（打遊戲的老二的影片、666bj 在 NGA 的整理）。
- 因子有品質之分，「卓越」最高（兩者相同）。
- 完成副本後，隊伍裡攜帶的奇波有機率突變；因子未滿 8 個時，突變新增一個因子（兩者相同）。

因子滿 8 個以後，兩者說法不同：老二的影片說突變隨機換掉其中一個因子，可以選擇保留原本的；666bj 的整理說只有落在第 2 到 8 格的突變才讓玩家選擇，落在第 1 格（先天因子）時，先天因子自動升一級品質（普通、優良、卓越）。老二的影片另外說，閃光奇波捕獲時多帶一個因子。
