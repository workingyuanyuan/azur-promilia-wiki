## 各服的語言

| 伺服器 | 營運 | 遊戲文字 |
| --- | --- | --- |
| 中國大陸（陸服） | 蠻啾網路 | 簡體中文 |
| 台港澳（台服） | JIMI | 繁體中文 |
| 日本（日服） | Yostar | 日文 |
| 韓國（韓服） | Nexon | 韓文 |

| 伺服器 | 配音 |
| --- | --- |
| 台服 | 中文、日語、韓語，可在設定切換 |
| 日服 | 只有日語 |
| 韓服 | 有韓語配音 |

每一服的遊戲文字只有一種語言。台服與日服設定裡的「語言」分頁只有配音語言一項，沒有切換文字語言的選項。

## 日服能不能設中文

不能。日服的文字只有日文，配音也只有日語：設定畫面只有「日本語」一個配音選項。[^1][^2]日服的使用者規約只適用於在日本國內使用這項服務。

## 帳號

| 項目 | 規則 |
| --- | --- |
| 跨平台 | 同一服之內，PC、Android、iOS 用同一帳號登入，進度相同 |
| 轉讓與交易 | 台服與日服都禁止轉讓、出借或交易帳號；日服也禁止把付費貨幣移到自己的另一個帳號 |
| 陸服換綁手機號 | 不能在遊戲內直接換綁。要換綁，須先到電信營業廳註銷原手機號，並提供新手機號的實名認證、手持身分證照片、儲值紀錄、註冊時間與裝置等資料[^3] |

## 英文版

英文版的 Open Beta 預定 2027 年夏季，使用美國的獨立伺服器；公測當天沒有英文服。
