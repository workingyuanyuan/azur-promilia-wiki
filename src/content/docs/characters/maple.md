## 人物與打法

楓糖是弗利斯城邦冒險公會的看板娘，獸人族，常駐角色。重擊、星決技、極限反擊與完美招架都讓她得到「喵喵連擊」，期間每次命中追加真實傷害，星鳴技也多出第二段；她的主要用途是提高全隊的攻擊力、傷害與超限強度。

## 公測改動

丸子在 Bilibili 的影片（2026-11-26）列出公測 1.0 與第三次測試的差別，箭頭前是第三次測試的數值：

| 技能 | 公測 1.0 的改動 |
| --- | --- |
| 閃亮旋風（星鳴技） | 攻擊力提高 10% → 5%，全隊傷害提高 10% → 5% |
| 肉墊衝擊（星決技） | 超限強度由固定值改為百分比：100 → 6% |
| 元氣鼓舞（星攜技） | 離場時取得的光印記 2 枚 → 1 枚 |
| 喵嗚鬥志（被動） | 全隊光與木屬性傷害提高，疊滿 3 層時 24% → 18% |
| 定弦 2、4、6 | 增益數值調整 |
