## 人物與打法

諾諾是帕米族，尋寶探險二人組的一員，不屬於任何陣營，常駐角色。她的核心是最多蓄力三段的重擊：蓄滿命中時消耗地印記打出超限傷害、提高架勢破壞效率，並替全隊與自己提高攻擊力；星鳴技與星決技之後都能直接接第二段蓄力。

## 公測改動

丸子在 Bilibili 的影片（2026-11-26）列出公測 1.0 與第三次測試的差別，箭頭前是第三次測試的數值：

| 技能 | 公測 1.0 的改動 |
| --- | --- |
| 咻咻嘿咻（普攻）、呼拉拉猛錘（星決技） | 新增「趁勝追擊」：架勢破壞後的敵人受到的非超限傷害提高 |
| 星結合擊 | 倍率提高 |
| 鐺鐺鐺（被動） | 加成 8% → 15% |
