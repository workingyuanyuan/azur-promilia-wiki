## 人物與打法

米砂是洛斯蘭瑟的木精靈族，守護山谷深處的一座花園，常駐角色。她的攻擊會在敵人身邊留下兩種種子：拾取「蝶生之種」替全隊回復生命值，拾取「靈木之種」為全隊補星決蓄能；普攻第四段、重擊和精準防禦還會替敵人加上降低防禦力的「荊棘」。

## 公測改動

丸子在 Bilibili 的影片（2026-11-26）比較了公測 1.0 與第三次測試：

| 技能 | 改動（第三次測試 → 公測 1.0） |
| --- | --- |
| 輕語（普攻） | 降低敵人防禦 20% → 21% |
| 森之祈願（星決技） | 改為固定提高風與木屬性傷害，上限 15% → 32% |
| 育樹之風（被動） | 觸發多了限制條件，數值不變 |
| 定弦 4 | 星鳴技的增傷上限提高 |
