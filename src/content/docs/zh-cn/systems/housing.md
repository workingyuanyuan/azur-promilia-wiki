## 采集设施

| 设施 | 奇波的工作 | 产出 |
| --- | --- | --- |
| 林果园 | [伐木](/zh-cn/kibo/work/#伐木) | 软木、硬木、纤维、斑红菇、红果、桃荔子、清月果、苦阳果、汁石 |
| 矿场 | [采矿](/zh-cn/kibo/work/#采矿) | 风铜矿、闪锡矿、镜铁矿、白银矿、尘石、坚岩、黄玉、蓝晶 |
| 星辉矿场 | [采矿](/zh-cn/kibo/work/#采矿) | 细碎的星结之辉 |
| 元素祭坛 | [元素](/zh-cn/kibo/work/#元素) | 九种属性的元素微粒 |
| 投食点 | [照料](/zh-cn/kibo/work/#照料) | 新鲜的兽肉、新鲜的禽肉、破损的兽皮、完整的兽皮；偶尔产出奇波蛋 |
| 牧场 | [照料](/zh-cn/kibo/work/#照料) | 放牧的奇波各自的产物（见[牧场](#牧场)） |
| 农场 | [耕作](/zh-cn/kibo/work/#耕作)、[浇水](/zh-cn/kibo/work/#浇水) | 作物：料理与布料的原料（见[农场](#农场)） |

- 采集设施只在派驻做该工作的奇波时产出。
- 春风满马的视频说投食点也产蛋与奶，且要先在牧场配置奇波才会产出；第三次测试的游戏资料与 666bj 的整理都把蛋与奶列为牧场的产物。

## 矿场

- 第三次测试的游戏资料里，上表的矿石都出自一座综合采矿场。公测的矿场有五座（春风满马的视频与 666bj 在 NGA 的整理相同），666bj 整理的各矿场产出如下：

| 矿场 | 产出 |
| --- | --- |
| 风铜矿场 | 风铜矿、尘石、黄玉 |
| 闪锡矿场 | 闪锡矿、尘石、黄玉 |
| 镜铁矿场 | 镜铁矿、坚岩、蓝晶 |
| 空铁矿场 | 空铁矿、坚岩、白银 |
| 星辉矿场 | 细碎的星结之辉 |

- 加工设施有较大的版本（纺织铺、制革铺、熔炼铺、料理铺、工作室），做的工作与基本版本相同。
- 春风满马的视频提到，加工设施没有派驻奇波时也会加工，只是很慢。

- 锻造铺随机产出装备；用织造图谱可指定产出的装备。
- 奇波工作会消耗饱腹值，饿了会到奇波餐桌吃那里的料理；料理由烹饪锅做。

## 农场

- 农场的田地要搭配耕作小屋，奇波才会自动耕作：做耕作的奇波播种、收割，做浇水的奇波灌溉。
- 一开始只有旱田；家园等级提高后有良田，产量较高，可种特殊果树。
- 作物有做料理的麦子，以及加工成布料的月麻、棉花。

## 家园等级

- 家园等级提高后，作物的质量、可派驻奇波的数量上限、田地数量上限与奇波餐桌的食物上限都随之提高。
