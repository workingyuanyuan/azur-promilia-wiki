## 各服的语言

| 服务器 | 营运 | 游戏文字 |
| --- | --- | --- |
| 中国大陆（陆服） | 蛮啾网络 | 简体中文 |
| 港澳台（台服） | JIMI | 繁体中文 |
| 日本（日服） | Yostar | 日文 |
| 韩国（韩服） | Nexon | 韩文 |

| 服务器 | 配音 |
| --- | --- |
| 台服 | 中文、日语、韩语，可在设定切换 |
| 日服 | 只有日语 |
| 韩服 | 有韩语配音 |

每一服的游戏文字只有一种语言。台服与日服设定里的「语言」分页只有配音语言一项，没有切换文字语言的选项。

## 日服能不能设中文

不能。日服的文字只有日文，配音也只有日语：PTT 玩家 2026-11-24 贴出的日服设定画面只有「日本语」一个配音选项，NGA 玩家开服当天的回报相同。日服的使用者规约只适用于在日本国内使用这项服务。

## 账号

| 项目 | 规则 |
| --- | --- |
| 跨平台 | 同一服之内，PC、Android、iOS 用同一账号登录，进度相同 |
| 转让与交易 | 台服与日服都禁止转让、出借或交易账号；日服也禁止把付费货币移到自己的另一个账号 |
| 陆服换绑手机号 | 不能在游戏内直接换绑。NGA 玩家贴出的客服回复（2026-11-26）：要换绑，须先到电信营业厅注销原手机号，并提供新手机号的实名认证、手持身分证照片、储值纪录、注册时间与装置等资料 |

## 英文版

英文版的 Open Beta 预定 2027 年夏季，使用美国的独立服务器；公测当天没有英文服。
