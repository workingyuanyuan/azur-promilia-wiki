## 星彩、闪光与异色

| 个体 | 说明 |
| --- | --- |
| 星彩奇波 | 外观特殊，例如菜叶带星空效果的[菜鸡](/zh-cn/kibo/caiji/)；属性与天赋与普通个体相同。同一种奇波可能有多种星彩外观 |
| 闪光奇波 | 有闪光因子、外观会闪光的奇波；闪光因子可能出现在普通奇波上，也可能出现在星彩奇波上 |
| 异色个体 | 部分特殊的奇波才有；部分奇波穿上装扮后，也呈现对应的异色外观 |

## 专属奇波

- 专属奇波是与某位角色缔结了契约的奇波个体。做完相关任务，或把该角色的牵绊等级提高，就能直接得到。
- 例如[霜刃狼](/zh-cn/kibo/shuangrenlang/)乌尔是[忒拉拉](/zh-cn/characters/terara/)的专属奇波；忒拉拉抚摸乌尔时有抚摸普通霜刃狼时没有的表现。

## 取得

| 方式 | 说明 |
| --- | --- |
| 星结卡 | 步行或骑乘时都能使用，不打断探索；星结卡的质量影响星结的效果 |
| 幻彩的星结卡 | 特殊的星结卡：容易星结成功，并把星结到的奇波变成星彩奇波 |
| 奇波蛋 | 活动奖励会给，野外也可能捡到。蛋的质量越高，越可能孵出资质高的奇波；有些特定的蛋孵出的是星彩或闪光个体 |

## 培养

| 培养 | 说明 |
| --- | --- |
| 潜能训练 | 拿另一只同名而属性较高的奇波陪练，提高基础属性 |
| 牵绊等级 | 提高奇波的牵绊等级，携带它的角色属性也提高 |

## 因子

- 每只奇波最多有 8 个因子，捕获时带 1 个先天因子。[^1][^2]
- 因子有质量之分，「卓越」最高。[^1][^2]
- 完成副本后，队伍里携带的奇波有机率突变；因子未满 8 个时，突变新增一个因子。[^1][^2]

因子满 8 个以后，两份玩家整理说法不同：打游戏的老二的视频说突变随机换掉其中一个因子，可以选择保留原本的；[^1]666bj 的整理说只有落在第 2 到 8 格的突变才让玩家选择，落在第 1 格（先天因子）时，先天因子自动升一级质量（普通、优良、卓越）。[^2]闪光奇波捕获时多带一个因子。[^1]
