## 特性

| 特性 | 效果 |
| --- | --- |
| 元素親和 | 自身受到的全屬性傷害降低7%，造成的全屬性傷害提高7%。 |
| 機靈可愛 | 自身入場時，攻擊力與架勢破壞效率提高14%，持續16秒。 |

## 技能

| 技能 | 種類 | 效果（等級 1） |
| --- | --- | --- |
| 雪律 | 固定技能 | 使冰屬性友方獲得「架勢破壞效率提高·大」效果，架勢破壞效率提高35%，持續16秒。對敵方降下7支寒冰長矛，每擊造成64.8%攻擊力的冰屬性傷害，並使友方全體獲得1枚冰印記。 |
| 爆裂冰矛 | 技能 | 在目標位置上方召喚大量冰矛並向目標位置發射，冰矛落地後爆炸，對範圍內敵方造成85.1%攻擊力的冰屬性傷害。 |
| 大雪球 | 技能 | 向敵方發射一個沿直線貼地滾動並緩慢變大的大雪球。大雪球命中後，對範圍內敵方至多造成42%攻擊力的冰屬性傷害。 |
| 碎冰刺擊 | 合擊技能 | 施放冰錐攻擊敵方，造成251.1%攻擊力的冰屬性傷害，對敵方架勢槽造成大量傷害。 |
