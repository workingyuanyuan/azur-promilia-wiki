## 特性

| 特性 | 效果 |
| --- | --- |
| 鋼尾 | 自身造成暴擊傷害時，賦予敵方「裂傷」效果，每秒造成2%攻擊力的無屬性傷害，持續30秒，至多可疊加3層。 |
| 聚能花紋 | 獲得印記時，自己恢復1點能量。 |

## 技能

| 技能 | 種類 | 效果（等級 1） |
| --- | --- | --- |
| 與風共舞 | 固定技能 | 喚出風暴區域，持續牽引敵方，對區域內的敵方至多造成1363.6%攻擊力的風屬性傷害，並在命中後使自身獲得「風舞」。區域消散時，再對區域內的敵方造成340.4%攻擊力的風屬性傷害。 「風舞」：每層提高持有者1.2%攻擊力，至多可疊加15層，持續16秒。 |
| 連射水彈 | 技能 | 向敵方發射3枚水彈，造成7.3%攻擊力的水屬性傷害。 |
| 旋風陣列 | 技能 | 在敵方周圍召喚4股環繞移動的龍捲風，每個龍捲風每秒對敵方至多造成12.2%攻擊力的風屬性傷害，持續1秒。龍捲風聚合成大型龍捲風，每秒對敵方至多造成46%攻擊力的風屬性傷害，持續3.2秒。 |
| 烈尾擊 | 合擊技能 | 攻擊敵方，造成251.1%攻擊力的風屬性傷害，對敵方架勢槽造成大量傷害。 |
